# 设备管理使用说明

> 适用范围：Dashboard 前端的设备管理视图（探针设备与 SNMP 设备），帮助运维/研发快速定位设备、查看详情、执行添加/编辑/删除等操作。

## 总览

- 入口视图：`dashboard/src/views/devices/Devices.vue`，提供两个页签：`探针设备` 与 `SNMP设备`。
- 标签页记忆：当前激活页签保存在 `localStorage` 的 `devices-active-tab` 中；离开路由前自动重置为 `探针设备`。
- 分页与状态：表格默认 `pageSize=30`，分页/排序/筛选变化会触发回调 `handleTableChange`。

## 探针设备

### 筛选与重置

- 支持按 `IP地址`、`设备类型`（台式机/笔记本/服务器/其他/未知）、`操作系统`（Windows/Linux）、`状态`（在线/离线）筛选。
- 点击 `重置` 立即清空所有筛选条件。

### 列表与状态显示

- 类型图标：预设类型（台式机/笔记本/服务器/打印机/防火墙/路由器/交换机）展示 SVG 图标，否则显示文本。
- 基本信息：`设备名称`、`设备别名`、`设备地址`（多个 IP 时显示第一个并提供 `(+N)` 提示，悬停查看完整列表）。
- 在线状态：以标签显示 `在线/离线`，离线设备的资源使用率显示为 `0%`。
- 系统/架构信息：`系统`、`版本`、`系统位数`（如 64位）、`硬件类型`。
- 使用率：`CPU`、`内存`、`磁盘` 使用率展示为百分比。
- 变更高亮：当 `timestamp / CPU / 内存 / 磁盘 / 服务数 / 进程数` 更新时，会在 3 秒内高亮该项，便于辨识实时变化。

### 详情查看

- 服务详情：打开服务列表（协议、监听地址、状态、进程信息）。
- 进程详情：打开进程列表，查看进程信息。
- 网口详情：查看各网口 `IP/MAC/网关/掩码/上传/下载速率` 等。

### 进程管理

- 顶部按钮 `进程管理` 打开统一的进程管理弹窗（`ProcessModal`）。

### 添加/编辑/删除

- 添加/编辑通过 `DeviceAddModal`：
  - 字段：`设备类型`、`设备名称`（编辑时不可修改）、`设备别名`。
  - 点击确定保存；失败会显示错误提示。
- 删除设备：带有确认弹窗；确认后调用删除接口。

### 实时更新

- 通过 WebSocket 订阅 `wsCode.DEVICE_STATUS` 与 `wsCode.DEVICE_INFO`，设备状态与信息实时刷新。
- 数据列表使用 `shallowRef` 优化大型数组渲染性能。

## SNMP 设备

### 筛选与重置

- 支持按 `设备名称`、`设备别名`、`设备类型`（打印机/防火墙/路由器/交换机/其他）、`状态`（在线/离线/未知）筛选。
- 点击 `重置` 清空筛选条件。

### 自动发现与手动添加

- 自动发现：打开 `SNMPScanModal`，扫描网络中的 SNMP 设备；扫描完成后可导入结果。
- 手动添加：打开 `SwitchAddModal`，填写 `IP`、`SNMP版本`（默认 2c）、`Community` 等创建设备。

### 列表与端口详情

- 列表显示类型图标、设备名称、IP 地址、状态等。
- `端口总数` 支持 Popover 展示接口明细表：`管理员状态` 与 `运行状态` 以标签颜色区分（启用/禁用、Up/Down）。

### 编辑/删除

- 编辑：打开 `SwitchAddModal`，更新交换机信息。
- 删除：带有确认弹窗；确认后调用删除接口。

### 实时更新

- 通过 WebSocket 订阅 `wsCode.SNMP_DEVICE_UPDATE`，同步列表状态变化。
- 与 `SNMPStorage` 结合管理扫描结果与接口数据的缓存/持久化。

## 常见操作

- 切换页签：`探针设备` 与 `SNMP设备` 两类管理分开进行；切换状态会记忆。
- 多 IP 查看：在设备地址列点击 `(+N)`，通过 Tooltip 查看其余 IP 地址。
- 快速排错：结合资源使用率与在线状态快速判断设备是否异常；离线时使用率归零。
- 批量查看接口：在 SNMP 设备列表中点击 `端口总数` 数字，弹出接口详情表进行查阅。

## 提示与注意

- 编辑模式下，探针设备的 `设备名称`不可修改；如需更改需删除后重新添加。
- 类型图标仅对预设类型提供；其他类型以文本显示。
- 变更高亮持续时间为 `3秒`；用于快速识别实时更新字段。
- 离开当前页面前会重置 `devices-active-tab=1`，返回时默认显示 `探针设备`。
